# Triage labels

The skills think in terms of five roles. This file maps each role to the label we actually write. We use the defaults, so the label is the same as the role name.

| Role | Label we write | What it means |
| --- | --- | --- |
| needs-triage | `needs-triage` | Nobody has decided what to do with this yet. |
| needs-info | `needs-info` | Waiting on the person who reported it. |
| ready-for-agent | `ready-for-agent` | Specified well enough that an agent can pick it up unattended. |
| ready-for-human | `ready-for-human` | A person needs to do this one. |
| wontfix | `wontfix` | We have decided not to act on it. |

The label goes on the `Status` line near the top of an issue file. Add `in-progress` or `done` if you find you want them.

When a skill refers to a role, such as asking you to apply the label that means an agent can take it, write the label from the middle column.
